# Contributing to Trucebearer

Thank you for helping. There is no contributor agreement to sign and no sign-off line to add. Open a pull request.

## How your contribution is licensed

A contribution is licensed under the nearest `LICENSE` file at or above the file it changes. The one exception is brand artwork (the logo, wordmark and icons), which stays CC BY-SA 4.0 wherever it is copied, including into `web/`. This is the same "inbound = outbound" rule that GitHub's Terms of Service already apply to every repository that states a license.

| Folder | License |
|---|---|
| `web/` | AGPL-3.0-or-later, with the additional term in `web/NOTICE` |
| `adjudicator/` | AGPL-3.0-or-later |
| Native app shells (when they exist) | MPL-2.0 |
| `assets/`, `docs/` | CC BY-SA 4.0 |
| Root files | AGPL-3.0-or-later |

By opening a pull request you confirm that you have the right to contribute the work under that license. You keep the copyright in what you write.

## Before you start

- Read `AGENTS.md` at the root and in the folder you are working in. The rules there apply to people as well as agents.
- A pull request changes one side only: `adjudicator/` or `web/`. Root files, `docs/`, `.github/` and license files go in pull requests of their own.
- Never copy text from the game's rulebook or from the DATC document. Write explanations in your own words and cite section numbers.
- Don't copy or translate code from other engines. Read them as references only.
- Write the test first, with RSpec.
