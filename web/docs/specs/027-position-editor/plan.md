# Plan 027: The host's position editor

**Spec:** `web/docs/specs/027-position-editor/spec.md` (v1.0.3, approved at Gate A)
**Branch:** `web/27-position-editor`

## Goal

The host edits the open phase's position one change at a time (add, move, remove a unit; set a supply center's owner; set the season and year), every edit is built and refused by `RulesEngine`, an edit that moves units clears every seat's orders, and every edit is recorded in an append-only `position_edits` table shown in the Seat history list. Host only, no JavaScript, 360 pixels.

## Gates checked

- **Simplicity:** the parts are one table and model (`PositionEdit`), one `Game` method (`edit_position!`) with two readers, one block in `RulesEngine`, one controller concern with four small controllers, one helper, one partial for the notice and one for `.segmented`. No dependency, no Stimulus, no JavaScript, no new gem call outside `RulesEngine`.
- **Anti-abstraction:** `PositionEdit.apply` (building the new position and the record's `detail` from an edit) is a class method of the model, not a new service class. The words helper is one helper module. The four controllers share one concern.
- **Integration-first:** Phase 1 is the first failing request spec; the engine contract (Phase 2) and the `Game` contract (Phase 3) are written and tested before any controller or view.

```ruby
  # ---- Editing a position (spec 027) ----
  # The host's hand edits of the open phase's position. Each builds a new position through the gem, which decides what is possible. A
  # refusal is explained from what the gem documents (the stage that raised, and the map's province types and coasts), never from the
  # text of its messages (spec 027 D5). One contiguous block, because #29 edits this file too.

  # A hand edit the gem refused or the app could not apply. The reason is a symbol of spec 027 D8 and the message is the symbol's
  # name: neither carries the gem's message, a position or an order.
  class EditRefused < StandardError
    attr_reader :reason

    def initialize(reason)
      @reason = reason
      super(reason.to_s)
    end
  end

  ProvinceInfo = Data.define(:id, :name, :coasts)

  module Editing
    def provinces = @provinces ||= TA::Map.classic.provinces.map { |p| ProvinceInfo.new(id: p.id.to_s, name: p.name, coasts: p.coasts.map(&:to_s)) }

    def supply_centers = @supply_centers ||= TA::Map.classic.supply_centers.map(&:to_s)

    def coasts = provinces.flat_map(&:coasts).uniq.sort

    def add_unit(position, power:, type:, province:, coast:)
      unit = build_unit(power, type, province, coast)
      rebuilt(position, units: position.units + [ unit ]) { taken?(position, province) ? :province_taken : :other }
    end

    def move_unit(position, from:, province:, coast:)
      old = unit_at(position, from)
      unit = build_unit(old.power.to_s, old.type.to_s, province, coast)
      rebuilt(position, units: position.units.reject { |u| u.equal?(old) } + [ unit ]) { taken?(position, province) ? :province_taken : :other }
    end

    def remove_unit(position, province:)
      old = unit_at(position, province)
      rebuilt(position, units: position.units.reject { |u| u.equal?(old) }) { :other }
    end

    # A nil power removes the entry (an unowned center is absent, interface.md "Position").
    def set_owner(position, center:, power:)
      text!(center)
      text!(power, nil_ok: true)
      raise EditRefused.new(:other) unless RulesEngine.province?(center) && (power.nil? || power?(power))

      ownership = position.ownership.dup
      power ? ownership[center.to_sym] = power.to_sym : ownership.delete(center.to_sym)
      rebuilt(position, ownership: ownership) { supply_centers.include?(center) ? :other : :not_a_center }
    end

    def set_date(position, season:, year:)
      text!(season)
      raise EditRefused.new(:other) unless year.is_a?(Integer)

      rebuilt(position, season: season.to_sym, year: year) { :other }
    end

    private

    # An argument that is not the text (or nil) it must be is a refusal, never a NoMethodError.
    def text!(value, nil_ok: false)
      raise EditRefused.new(:other) unless value.is_a?(String) || (nil_ok && value.nil?)
    end

    def power?(id) = RulesEngine.powers.any? { |power| power.id.to_s == id }

    def unit_at(position, province)
      text!(province)
      position.units.find { |u| u.location.province.to_s == province } || raise(EditRefused.new(:no_unit))
    end

    def taken?(position, province) = position.units.any? { |u| u.location.province.to_s == province }

    # Stage 0 (an unknown identifier) is :other; stage 1 builds the location; stage 2 builds the unit (spec 027 D5).
    def build_unit(power, type, province, coast)
      text!(power)
      text!(type)
      text!(province)
      text!(coast, nil_ok: true)
      raise EditRefused.new(:other) unless RulesEngine.province?(province) && power?(power) && %w[army fleet].include?(type)

      location = begin
        TA::Location.new(province: province.to_sym, coast: coast&.to_sym)
      rescue TA::InvalidInput
        raise EditRefused.new(coast ? :no_such_coast : :other)
      end
      begin
        TA::Unit.new(power: power.to_sym, type: type.to_sym, location: location)
      rescue TA::InvalidInput
        raise EditRefused.new(unit_reason(type, province, coast))
      end
    end

    def unit_reason(type, province, coast)
      info = TA::Map.classic.province(province.to_sym)
      if type == "army"
        return :army_at_sea if info.type == :sea
        return :army_coast if coast
      else
        return :fleet_inland if info.type == :inland
        return :fleet_needs_coast if coast.nil? && info.coasts.any?
      end
      :other
    end

    # Stage 3: the whole position. The block names the reason when the gem refuses it.
    def rebuilt(position, **changes)
      TA::Position.new(map: position.map, season: position.season, year: position.year, phase: position.phase, units: position.units,
                       ownership: position.ownership, dislodged_units: position.dislodged_units, standoffs: position.standoffs, **changes)
    rescue TA::InvalidInput
      raise EditRefused.new(yield)
    end
  end
  extend Editing
  private_constant :Editing
```

Inside `module Editing`, `TA` resolves lexically (as in `StandIn`), `RulesEngine.province?` and `RulesEngine.powers` are the existing singleton methods. Because a private method of an extended module stays private on the singleton, `RulesObjectType#load_value`'s `public_send` of the existing loaders is unaffected. The spec's `ProvinceInfo` and `EditRefused` are `RulesEngine::ProvinceInfo` and `RulesEngine::EditRefused` as the specs expect.

Two more engine examples, written first: `set_owner(center: nil, power: nil)` and `add_unit(power: nil, type: "fleet", province: "mun", coast: nil)` are `EditRefused(:other)`, not a `NoMethodError`; an unknown power with a fleet in `mun` is `:other` (stage 0 comes first), and `set_owner(center: "xyz", ...)` is `:other`.

```ruby
# One hand edit of the open phase's position by the host (spec 027 D4). It never changes and is never deleted. It holds board facts
# only: no order, no count of orders, nothing about who had ordered.
class PositionEdit < ApplicationRecord
  SHAPES = {
    "unit_added" => %w[power type province coast], "unit_moved" => %w[power type from from_coast to to_coast],
    "unit_removed" => %w[power type province coast], "owner_set" => %w[center from to],
    "date_set" => %w[from_season from_year to_season to_year]
  }.freeze
  INTEGERS = %w[from_year to_year].freeze
  CLEARING = %w[unit_added unit_moved unit_removed].freeze

  Result = Data.define(:position, :detail)

  belongs_to :phase

  validate :detail_has_a_known_shape

  def readonly? = persisted? || super
  def kind = :position_edit
  def clears_orders? = CLEARING.include?(detail["action"])

  # The new position and the record's detail for one intent (a string-keyed hash: "action" and the host's choices). It asks
  # RulesEngine for the position and refuses what the engine refuses. Called by Game#edit_position!, under the phase lock.
  def self.apply(position, intent)
    case intent["action"]
    when "unit_added"
      new_position = RulesEngine.add_unit(position, power: intent["power"], type: intent["type"], province: intent["province"], coast: intent["coast"])
      Result.new(new_position, intent.slice("action", "power", "type", "province", "coast"))
    when "unit_moved"
      unit = position.units.find { |u| u.location.province.to_s == intent["from"] }
      new_position = RulesEngine.move_unit(position, from: intent["from"], province: intent["to"], coast: intent["to_coast"])
      Result.new(new_position, { "action" => "unit_moved", "power" => unit.power.to_s, "type" => unit.type.to_s, "from" => intent["from"],
                                 "from_coast" => unit.location.coast&.to_s, "to" => intent["to"], "to_coast" => intent["to_coast"] })
    when "unit_removed"
      unit = position.units.find { |u| u.location.province.to_s == intent["province"] }
      new_position = RulesEngine.remove_unit(position, province: intent["province"])
      Result.new(new_position, { "action" => "unit_removed", "power" => unit.power.to_s, "type" => unit.type.to_s,
                                 "province" => intent["province"], "coast" => unit.location.coast&.to_s })
    when "owner_set"
      new_position = RulesEngine.set_owner(position, center: intent["center"], power: intent["to"])
      Result.new(new_position, { "action" => "owner_set", "center" => intent["center"], "from" => position.ownership[intent["center"].to_sym]&.to_s, "to" => intent["to"] })
    when "date_set"
      new_position = RulesEngine.set_date(position, season: intent["to_season"], year: intent["to_year"])
      Result.new(new_position, { "action" => "date_set", "from_season" => position.season.to_s, "from_year" => position.year,
                                 "to_season" => intent["to_season"], "to_year" => intent["to_year"] })
    else raise RulesEngine::EditRefused.new(:other)
    end
  end

  private

  def detail_has_a_known_shape
    keys = SHAPES[detail.is_a?(Hash) ? detail["action"] : nil]
    return errors.add(:detail, "is not one of the five shapes") unless keys && detail.keys.sort == ([ "action" ] + keys).sort

    bad = detail.reject { |key, value| key == "action" || value.nil? || (INTEGERS.include?(key) ? value.is_a?(Integer) : value.is_a?(String)) }
    errors.add(:detail, "holds a value of the wrong kind") if bad.any?
  end
end
```

`Game` (in `game.rb`, after `reissue_seat!`):

```ruby
  # One hand edit of the open phase's position by the host (spec 027 D1, D3, D4, D7). It runs under the phase lock, builds the new
  # position through RulesEngine, refuses a change that changes nothing, stores the position, clears every seat's orders when units
  # moved, and writes the record, all in one transaction. Returns the new PositionEdit row. The status stream hears of it after the
  # commit when a submission was withdrawn, as for a reissue (spec 024 D3).
  def edit_position!(number, intent)
    withdrew = false
    row = transaction do
      phase = phases.lock.find_by!(revealed_at: nil) # read under the lock, so a reveal can't slip in between
      raise Phase::Revealed unless phase.number == number

      result = PositionEdit.apply(phase.position, intent)
      raise RulesEngine::EditRefused.new(:no_change) if result.position == phase.position

      phase.update!(position: result.position)
      entry = PositionEdit.create!(phase: phase, detail: result.detail)
      withdrew = seats.map { |seat| seat.clear_orders!(phase) }.any? if entry.clears_orders?
      entry
    end
    broadcast_seat_status if withdrew
    row
  end

  # Every position edit of this game, oldest first. Read through the phases, as the other histories are (spec 027 D4).
  def position_edit_history = PositionEdit.joins(:phase).where(phases: { game_id: id }).includes(:phase).order(:id)

  # When the latest edit that moved units was made in this phase, or nil: what a seat's notice says (spec 027 D3).
  def board_cleared_at(phase) = PositionEdit.where(phase_id: phase.id).select(&:clears_orders?).map(&:created_at).max
```

The concern:

```ruby
# What the four position-editor controllers share (spec 027 D1, D6, D8): the host check, the phase check, the headers, the "Choose ..."
# checks that run before any gem call, and the answer to one edit.
module PositionEditing
  extend ActiveSupport::Concern

  SEASONS = %w[spring fall].freeze
  YEARS = (1901..1999)

  class Choose < StandardError; end # the message is the sentence the host sees

  included do
    before_action :require_host
    before_action :find_open_phase
    before_action :editor_headers
    helper_method :editor_path, :field
  end

  private

  # A revealed phase goes to the host page like the reveal does; a later, unknown or malformed number is the stranger response.
  def find_open_phase
    @phase = find_phase(@game)
    return stranger!(@game) unless @phase && @phase.number <= @game.current_phase.number
    return if @phase.open?

    revealed
  end

  def revealed
    flash[:banner] = { "kind" => "info", "text" => "That phase was already revealed." }
    redirect_to game_host_path(@game.public_id), status: :see_other
  end

  def editor_headers
    no_store
    response.set_header("Referrer-Policy", "no-referrer")
  end

  def editor_path = game_position_path(@game.public_id, @phase.number)

  # A string field of a nested form, or nil when it is missing, not a string, or the form is not a hash.
  def field(group, key)
    fields = params[group]
    value = fields.respond_to?(:key?) ? fields[key] : nil
    value.is_a?(String) ? value : nil
  end

  def choose!(value, allowed, sentence)
    raise Choose, sentence unless allowed.include?(value)

    value
  end

  def power!(value) = choose!(value, RulesEngine.powers.map { |p| p.id.to_s }, "Choose a power.")
  def province!(value) = choose!(value, RulesEngine.provinces.map(&:id), "Choose a province.")
  def coast!(value) = value.blank? ? nil : choose!(value, RulesEngine.coasts, "Choose a coast.")

  # Applies one edit and answers: a redirect with the banner, or the form again with the sentence (422). `form` is the template to
  # draw again. A vanished unit is the stranger response (spec 027 D7).
  def edit!(form)
    row = @game.edit_position!(@phase.number, yield)
    cleared = row.clears_orders? ? "Saved orders for this phase were cleared." : "Orders are kept."
    flash[:banner] = { "kind" => "info", "text" => "Saved. #{helpers.position_edit_text(row.detail)}. #{cleared}" }
    redirect_to editor_path, status: :see_other
  rescue Phase::Revealed then revealed
  rescue Choose => error then refuse(form, error.message)
  rescue RulesEngine::EditRefused => error
    return stranger!(@game) if error.reason == :no_unit

    refuse(form, helpers.refusal_text(error.reason, province: @refused_province, coast: @refused_coast))
  end

  def refuse(form, sentence)
    @refusal = sentence
    render form, status: :unprocessable_content
  end
end
```

The controllers (one shown; the others follow the same shape):

```ruby
class PositionUnitsController < ApplicationController
  include PositionEditing

  before_action :find_unit, only: %i[show update destroy]

  def new; end

  def create
    @refused_province = field(:unit, :province)
    @refused_coast = field(:unit, :coast)
    edit!(:new) do
      { "action" => "unit_added", "power" => power!(field(:unit, :power)),
        "type" => choose!(field(:unit, :type), %w[army fleet], "Choose army or fleet."),
        "province" => province!(@refused_province), "coast" => coast!(@refused_coast) }
    end
  end

  def show; end

  def update
    @refused_province = field(:unit, :province)
    @refused_coast = field(:unit, :coast)
    edit!(:show) { { "action" => "unit_moved", "from" => @province, "to" => province!(@refused_province), "to_coast" => coast!(@refused_coast) } }
  end

  def destroy
    edit!(:show) { { "action" => "unit_removed", "province" => @province } }
  end

  private

  # The unit's province in the path: a province of the map that holds a unit in the open phase, else the stranger response.
  def find_unit
    @province = params[:province].to_s
    @unit = @phase.position.units.find { |unit| unit.location.province.to_s == @province }
    stranger!(@game) unless @unit
  end
end
```
